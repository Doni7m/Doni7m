# 💫 About Me

Hi, I'm Doni 👋 Brazilian, based in Madeira, Portugal. Law degree, wine-industry operations, and self-taught developer. I build tools that remove manual work from regulated, paperwork-heavy businesses.

🔭 **Currently working on**
- **[CruStudio](https://crustudio.site)**: solo consultancy offering compliance and web services to small US wine importers.
- **Madeira Times**: news site built with React, Vite and Supabase (SEO and monetization).
- **Wine import compliance automation**: TTB / COLA / CBMA workflows, price postings and documentation, using Python and GitHub Actions.
- Websites and web apps for local businesses in Madeira.

🤝 **Open to collaborate on**
- Automation for compliance-heavy workflows (wine, import/export, documentation)
- Web projects with React, Node.js and Supabase
- AI applied to business operations (agents, RAG, document processing)

🌱 **Currently learning**
- Software architecture for larger projects (structure, OOP, separation of concerns)
- AI-assisted workflows and agents applied to real business problems
- Dry bulk shipping and maritime logistics

💬 **Ask me about**
- US wine importer compliance (TTB, COLA, CBMA)
- Automating operations with Python and GitHub Actions
- Building content sites with React + Supabase

⚡ **Fun fact**
I once hitchhiked from Goiânia to Brasília, inspired by *On the Road* by Jack Kerouac, which I read at 14. It was spontaneous and unforgettable, and it sparked my love for exploration and new challenges.
